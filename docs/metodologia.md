# Metodologia

O grupo usou **Scrum**, com o quadro no **Jira**: backlog com as histórias de usuário e tarefas separadas por integrante.

| Papel | Integrante |
|---|---|
| Dev Fullstack / Scrum Master | Silas |
| Dev Frontend | Luiz |
| Dev Backend / BLE | Kaynan |
| Dev Backend / Controlers | João |

- **Sprints:** a cada entrega semanal, conversa com planejamento da proxima semana.
- **Definição de pronto:** código em PR, revisado por outro membro, com testes.
